About .env Mining Workstation Version 1.0.4 (Windows x64)

.env Miner is a high-performance, unified GPU & CPU multi-algorithm cryptocurrency mining suite designed for Windows x64 and remote Linux rigs. Equipped with integrated hardware telemetry, instant pool failover routing, and automated background ProcessGuard management.

What's New in v1.0.4:
  • Rigor (RGR) Engine Integrated: Added native OpuHash / SHA3-256 CPU mining with multi-thread allocation. Preconfigured dev payout: rg1q9m002y0hpuy9kxrtpud3pex2pj7kypjxjh60t9.
  • Dedicated Studio Sections: GPU Studio and CPU Studio separated into specialized workflows with custom hardware telemetry gauges.
  • Pro Obsidian Theme: Cyber obsidian aesthetic with ambient glow cards, responsive stat displays, and full English localization.
  • 14 Coins Pre-Configured: Full support across RGR, MDS, NRB, JTM, TSC, BNT, ZCD, YSR, PRL, QTC, NOID, CMFD, NACR, and XID.

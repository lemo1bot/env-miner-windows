## 💎 Supported Coins & Algorithms
- **Rigor (RGR)** - OpuHash CPU (`.env Rigor Engine` / `rigor-miner`)
- **Midstate (MDS)** - BLAKE3 PoW (`.env MDS Engine`)
- **Nerbus (NRB)** - VerusHash CPU (`.env NRB Engine`)
- **Jetsam (JTM)** - TowerWalk CPU (`.env JTM Engine`)
- **Blocknet (BNT)** - Argon2id (`.env Blocknet CPU` / `Seine`)
- **Zycord (ZCD)** - RandomX v2 (`.env XMRig CPU`)
- **YSKAR (YSR)** - SHA-256d (`.env YSR CUDA`)
- **Pearl (PRL)** - PearlHash (`KRig`)
- **Quantus (QTC)** - Poseidon2 (`KRig` / `.env QTC Engine`)
- **Parano1d (NOID)** - Poseidon2b (`Suprminer`)
- **TensorCash (TSC)** - Tensor PoW (`KRig` / `.env TSC GPU Engine`)
- **Common Foundry (CMFD)** - ForgeMatrix (`aria-energy-cmfd`)
- **Nacre (NACR)** - PearlHash AuxPoW (`KRig` / `nacre-miner`)
- **xCoin (XID)** - MetalDAG (`aria-energy-xid`)

## 🚀 Key Features
- **Modern Left-Sidebar UI**: Dark obsidian + cyber green terminal aesthetic.
- **Preconfigured Pools**: Configured for official community pools including bntpool.com, commonfoundry, nacre, ariabrain, midstate, nerbus, jetsam, and rigor nodes.
- **CPU & GPU Multi-Threading**: Granular thread and device allocation for optimal hashrates and system responsiveness.
- **Remote Cloud VPS Mining**: Connect and mine directly to remote Linux VPS / cloud rigs over SSH.
- **Real-Time Hardware Telemetry**: Accurate per-device GPU/CPU clocks, wattage, fan speeds, and temperatures.

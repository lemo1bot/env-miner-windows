## 💎 Supported Coins & Algorithms
- **Common Foundry (CMFD)** - ForgeMatrix (`aria-energy-cmfd`)
- **Nacre (NACR)** - PearlHash AuxPoW (`KRig` / `nacre-miner`)
- **xCoin (XID)** - MetalDAG (`aria-energy-xid`)
- **Blocknet (BNT)** - Argon2id (`.env Blocknet CPU` / `Seine`)
- **Zycord (ZCD)** - RandomX v2 (`.env XMRig CPU`)
- **YSKAR (YSR)** - SHA-256d (`.env YSR CUDA`)
- **Pearl (PRL)** - PearlHash (`KRig`)
- **Quantus (QTC)** - Poseidon2 (`KRig` / `.env QTC Engine`)
- **Parano1d (NOID)** - Poseidon2b (`Suprminer`)
- **TensorCash (TSC)** - Tensor PoW (`KRig` / `.env TSC GPU Engine`)

## 🚀 Key Features
- **Modern Left-Sidebar UI**: Dark obsidian + cyber green terminal aesthetic.
- **1-Click Built-in Wallet Generator**: Generate instant real wallets and private keys with BIP-39 mnemonic backup directly on your device for CMFD, NACR, XID, NOID, ZCD, BNT, YSR, QTC, and TSC.
- **Zero Chinese Text / Full English Localization**: Clean, professional logs, tables, hardware monitors, and error dialogs.
- **Preconfigured Pools**: Configured for official community pools including bntpool.com, commonfoundry, nacre, and ariabrain.
- **Remote Cloud VPS Mining**: Deploy and manage mining rigs over SSH directly from the desktop application.
- **Hardware Telemetry**: Accurate per-device GPU/CPU clocks, wattage, fan speeds, and temperatures.
